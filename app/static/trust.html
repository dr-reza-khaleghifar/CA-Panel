راهنمای اتصال امن به سامانه

گواهی امنیتی این سامانه باید مورد اعتماد مرورگر شما باشد.

«گواهی دیجیتال ایران» از یک Root CA اختصاصی استفاده می‌کند. اگر مرورگر هشدار «مرجع صادرکننده ناشناخته» نمایش می‌دهد، ممکن است گواهی ریشه هنوز در دستگاه شما مورد اعتماد قرار نگرفته باشد.

برای ورود امن، ابتدا هویت گواهی ریشه را از مسیر مستقل تأیید کنید و سپس آن را فقط با تأیید مدیر یا مالک دستگاه در مخزن گواهی‌های مورد اعتماد نصب کنید.

سه گام برای اتصال امن

  1. ۱

    دریافت گواهی عمومی ریشه

    فقط root-ca.pem عمومی قابل دریافت است؛ هیچ کلید خصوصی یا بسته مدیریتی در HTTP ارائه نمی‌شود.

    دریافت گواهی عمومی Root CA
  2. ۲

    تأیید مستقل اثر انگشت SHA-256

    اثر انگشت واقعی گواهی را از مدیر CA از یک کانال مستقل و معتبر (مثلاً حضوری یا پیام امضاشده و از قبل مورد اعتماد) دریافت و با فایل دانلودشده مقایسه کنید. اثری که صرفاً روی همین HTTP نمایش داده شود برای اثبات اصالت کافی نیست.

    Windows PowerShellcertutil -hashfile iran-ca-center-root.pem SHA256
    Linux / macOS (OpenSSL)openssl x509 -in iran-ca-center-root.pem -noout -fingerprint -sha256
  3. ۳

    نصب گواهی و ورود از HTTPS

    فایرفاکس: Settings ← Privacy & Security ← Certificates ← View Certificates ← Authorities ← Import. فایل ریشه را انتخاب کنید و فقط پس از بررسی اثر انگشت تأیید کنید.

    ویندوز: با اجازه مالک یا مدیر دستگاه، فایل ریشه را در Trusted Root Certification Authorities نصب کنید. این کار به کل Root CA برای اعتبارسنجی گواهی‌ها اعتماد می‌دهد، نه فقط به همین سایت.

    بازگشت به ورود امن HTTPS
این صفحه فقط راهنمای اعتماد به گواهی است؛ تمامی عملیات مدیریتی، صدور و دانلود محرمانه صرفاً روی HTTPS انجام می‌شوند.
