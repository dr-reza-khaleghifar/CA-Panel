STEP 02 · VERIFY

اثر انگشت را پیش از نصب بررسی کنید

اثر انگشت SHA-256 گواهی ریشه فعلی CA-Panel را با خروجی دستگاه خود مقایسه کنید. هنگام دانلود از HTTP، این مرحله اهمیت ویژه‌ای دارد. اگر حتی یک رقم متفاوت بود، فایل را نصب نکنید.

SHA-256 · ROOT CERTIFICATEمقدار مرجع
0E:3B:D2:5A:45:8A:0A:7E:48:5F:0C:2F:F1:BD:8A:67:59:6A:B2:47:D7:74:D2:64:31:D8:3C:44:1A:12:A6:06
این مقدار را از یک کانال مستقل و مورد اعتماد نیز با مدیر سامانه تطبیق دهید؛ به همان صفحه دانلود به‌تنهایی اکتفا نکنید.

Windows · PowerShell یا CMD

برای فایل CER با قالب DER:

certutil -hashfile ca-panel-root-ca.cer SHA256

هش فایل DER باید با اثر انگشت بالا یکسان باشد.

macOS و Linux · OpenSSL

برای فایل CER:

openssl x509 -inform DER -in ca-panel-root-ca.cer -noout -fingerprint -sha256

برای فایل PEM:

openssl x509 -in ca-panel-root-ca.pem -noout -fingerprint -sha256
i
نکته درباره SHA-256اثر انگشت، هشِ محتوای رمزگذاری‌شده گواهی است؛ با هش فایل PEM فرق دارد. در Windows از فایل CER/DER برای دستور certutil -hashfile استفاده کنید.
STEP 03 · INSTALL

راهنمای نصب بر اساس دستگاه

سیستم‌عامل و نسخه دستگاه را انتخاب کنید. نام بعضی منوها ممکن است با سازنده یا نسخه نرم‌افزار کمی تفاوت داشته باشد.

WindowsmacOSiPhone / iPad AndroidLinuxChromeOS مرورگرهاJavaسایر دستگاه‌ها
کامپیوتر و لپ‌تاپ
Windows 11 و Windows 10 CER · کاربر فعلی یا کل سیستم
  1. فایل CER را دانلود و اثر انگشت آن را با بخش قبل مقایسه کنید.
  2. برای نصب فقط در حساب کاربری فعلی، PowerShell را باز کنید و اجرا کنید:
certutil -user -addstore Root "$env:USERPROFILE\Downloads\ca-panel-root-ca.cer"

اگر فایل در Downloads نیست، مسیر را با محل واقعی آن جایگزین کنید.

نصب برای همه کاربران رایانه: فقط با دسترسی مدیر، PowerShell را با گزینه Run as administrator اجرا کنید:

certutil -addstore -f Root "$env:USERPROFILE\Downloads\ca-panel-root-ca.cer"
روش گرافیکی
  1. کلیدهای Win + R را بزنید و certmgr.msc را برای حساب فعلی یا certlm.msc را برای کل رایانه اجرا کنید.
  2. به Trusted Root Certification Authorities → Certificates بروید.
  3. روی Certificates راست‌کلیک کنید و All Tasks → Import را انتخاب کنید.
  4. فایل CER تأییدشده را انتخاب و مراحل را کامل کنید.

Chrome و Edge معمولاً از مخزن اعتماد Windows استفاده می‌کنند. برای Firefox ممکن است واردکردن جداگانه لازم باشد.

مستندات Microsoft درباره Trusted Root Store
macOS · MacBook و iMac Keychain Access
  1. فایل CER را دریافت و اثر انگشت آن را بررسی کنید.
  2. برنامه Keychain Access را از Spotlight باز کنید.
  3. برای اعتماد در سطح سیستم، System و برای اعتماد در حساب فعلی، login را انتخاب کنید.
  4. از File → Import Items فایل گواهی را وارد کنید.
  5. گواهی را باز کنید، بخش Trust را گسترش دهید و فقط پس از بررسی اثر انگشت، سیاست When using this certificate را روی Always Trust قرار دهید.

روش خط فرمان برای نصب در مخزن سیستم (نیازمند رمز مدیر):

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Downloads/ca-panel-root-ca.cer

Safari از زنجیره اعتماد سیستم استفاده می‌کند؛ Firefox ممکن است تنظیم جداگانه بخواهد.

راهنمای Apple برای Keychain Access
Linux · Ubuntu و Debian PEM · مخزن سیستم

فایل PEM را در پوشه Downloads قرار دهید و این دستورات را اجرا کنید:

sudo install -m 0644 ~/Downloads/ca-panel-root-ca.pem /usr/local/share/ca-certificates/ca-panel-root-ca.crt
sudo update-ca-certificates

برای بررسی ثبت گواهی:

ls -l /etc/ssl/certs | grep ca-panel-root-ca

بعضی برنامه‌های Snap، مرورگرها یا ابزارهای دارای مخزن اختصاصی ممکن است به تنظیم جداگانه نیاز داشته باشند.

مستندات رسمی Ubuntu
Linux · Fedora، RHEL، Rocky و AlmaLinux PEM · update-ca-trust

گواهی PEM را به پوشه trust anchors اضافه کنید:

sudo install -m 0644 ~/Downloads/ca-panel-root-ca.pem /etc/pki/ca-trust/source/anchors/ca-panel-root-ca.pem
sudo update-ca-trust extract

اگر دستور update-ca-trust موجود نیست، بسته مدیریت گواهی توزیع خود را از مخزن رسمی نصب کنید.

Linux · Arch و توزیع‌های مبتنی بر Arch PEM · p11-kit 
sudo install -m 0644 ~/Downloads/ca-panel-root-ca.pem /etc/ca-certificates/trust-source/anchors/ca-panel-root-ca.pem
sudo trust extract-compat

در صورت نبود دستور trust، بسته p11-kit را از مخزن رسمی توزیع نصب کنید.

ChromeOS و Chromebook PEM · Certificate Manager
  1. فایل PEM را دانلود و اثر انگشت آن را بررسی کنید.
  2. در Chrome نشانی chrome://certificate-manager را باز کنید؛ در برخی نسخه‌ها مسیر از Settings → Privacy and security → Security → Manage certificates است.
  3. در بخش Authorities گزینه Import را بزنید و فایل PEM را انتخاب کنید.
  4. فقط اعتماد لازم برای شناسایی وب‌سایت‌ها را فعال کنید.

در Chromebookهای تحت مدیریت مدرسه یا سازمان، ممکن است نصب فقط از طریق مدیر Google Admin و سیاست‌های سازمانی مجاز باشد.

Android · Pixel، Samsung، Xiaomi و سایر سازندگان CER · User credentials
  1. فایل CER را دانلود و اثر انگشت آن را بررسی کنید.
  2. Settings → Security & privacy → More security settings → Encryption & credentials را باز کنید. مسیر در مدل‌های مختلف متفاوت است.
  3. Install a certificate یا Install from storage و سپس CA certificate را انتخاب کنید.
  4. فایل را از Downloads انتخاب کنید و در صورت درخواست، PIN یا رمز قفل دستگاه را وارد کنید.
  5. در Trusted credentials → User وجود گواهی نصب‌شده را بررسی کنید.

محدودیت فعلی این صفحهاین سامانه در حال حاضر فایل CER و PEM ارائه می‌کند، نه پروفایل نصب iOS با فرمت .mobileconfig. فایل CER خام در همه نسخه‌های iOS به‌صورت یکسان قابل نصب نیست. برای نصب مطمئن، از پروفایل امضاشده‌ای که مدیر دستگاه یا سازمان از کانال مورد اعتماد ارائه می‌کند، یا از MDM / Apple Configurator استفاده کنید.

پس از نصب پروفایل Root CA و تأیید اثر انگشت، برای فعال‌کردن اعتماد کامل به مسیر زیر بروید:

Settings → General → About → Certificate Trust Settings

در بخش Enable Full Trust for Root Certificates، اعتماد به CA موردنظر را فعال کنید. نصب پروفایل به‌تنهایی لزوماً Full Trust را فعال نمی‌کند.

Firefox در Windows، macOS و Linux

  1. Settings → Privacy & Security → Certificates → View Certificates را باز کنید.
  2. در زبانه Authorities گزینه Import را بزنید.
  3. فایل CER یا PEM تأییدشده را انتخاب کنید.
  4. گزینه Trust this CA to identify websites را فقط پس از بررسی اثر انگشت فعال کنید.

در برخی نسخه‌ها می‌توانید استفاده از گواهی‌های اعتمادشده سیستم را فعال کنید؛ رفتار Firefox به نسخه و سیاست سازمانی بستگی دارد.

Chrome و Edge

در Windows و macOS معمولاً از مخزن اعتماد سیستم‌عامل استفاده می‌کنند. در Linux و ChromeOS، روش نصب به توزیع و تنظیمات مرورگر وابسته است. اگر پس از نصب هنوز خطای صادرکننده ناشناخته می‌بینید، مخزن گواهی مرورگر را نیز بررسی کنید.

Safari

Safari از زنجیره اعتماد سیستم Apple استفاده می‌کند. در macOS از Keychain و در iOS/iPadOS از Certificate Trust Settings استفاده کنید.

راهنمای Mozilla برای مدیریت CA در Firefox
Java و برنامه‌های دارای Trust Store اختصاصی keytool · PKCS12

برخی برنامه‌ها از مخزن اعتماد سیستم‌عامل استفاده نمی‌کنند. برای ساخت یک truststore جداگانه Java اجرا کنید:

keytool -importcert -alias ca-panel-root -file ca-panel-root-ca.cer -keystore ca-panel-truststore.p12 -storetype PKCS12

رمز را در prompt وارد کنید و اثر انگشت نمایش‌داده‌شده را با مقدار رسمی همین صفحه مقایسه کنید. سپس برنامه را برای استفاده از truststore جدید پیکربندی کنید. از تغییر سراسری فایل cacerts جاوا بدون هماهنگی مدیر سیستم خودداری کنید.

تلویزیون هوشمند، کنسول بازی، روتر و دستگاه‌های IoT وابسته به سازنده

برای این دستگاه‌ها روش نصب یکسانی وجود ندارد. بسیاری از مدل‌ها نصب Root CA سفارشی را پشتیبانی نمی‌کنند یا فقط گواهی‌های از پیش نصب‌شده را می‌پذیرند. فقط مستندات رسمی همان مدل و نسخه را دنبال کنید و از روش‌های غیررسمی برای تغییر مخزن اعتماد استفاده نکنید.

REMOVE TRUST

چطور اعتماد را حذف کنم؟

اگر دیگر نمی‌خواهید دستگاه به این Root CA اعتماد کند، گواهی را از همان مخزنی که نصب کرده‌اید حذف کنید. در دستگاه سازمانی، ابتدا با مدیر IT هماهنگ کنید.

Windows

در certmgr.msc (حساب فعلی) یا certlm.msc (کل رایانه)، به Trusted Root Certification Authorities → Certificates بروید و فقط گواهی CA-Panel با Subject و اثر انگشت مطابق را حذف کنید.

macOS

Keychain Access را باز کنید، زنجیره login یا System را انتخاب کنید، گواهی CA-Panel را با اثر انگشت تطبیق دهید و حذف کنید.

iPhone و iPad

به Settings → General → VPN & Device Management بروید و پروفایل مربوط به CA-Panel را حذف کنید. اگر Full Trust را جداگانه فعال کرده‌اید، آن را نیز غیرفعال کنید.

Android

در Settings → Security → Encryption & credentials → User credentials، گواهی CA-Panel را انتخاب و حذف کنید. نام منو بسته به سازنده متفاوت است.

Ubuntu و Debian
sudo rm /usr/local/share/ca-certificates/ca-panel-root-ca.crt
sudo update-ca-certificates --fresh
Fedora و RHEL
sudo rm /etc/pki/ca-trust/source/anchors/ca-panel-root-ca.pem
sudo update-ca-trust extract
Arch
sudo rm /etc/ca-certificates/trust-source/anchors/ca-panel-root-ca.pem
sudo trust extract-compat
Firefox

Settings → Privacy & Security → Certificates → View Certificates → Authorities را باز کنید، CA-Panel را پیدا و حذف کنید.

FAQ

پرسش‌های متداول

آیا با نصب این گواهی، همه وب‌سایت‌های اینترنت معتبر می‌شوند؟

خیر. فقط گواهی‌هایی که زنجیره اعتبارشان به همین Root CA ختم شود تحت تأثیر قرار می‌گیرند. گواهی‌های صادرشده توسط CAهای عمومی دیگر از این نصب استفاده نمی‌کنند.

آیا این Root CA به‌صورت پیش‌فرض در Chrome، Firefox یا Safari مورد اعتماد است؟

خیر. این یک CA خصوصی است و در برنامه‌های عمومی اعتماد ریشه مرورگرها قرار ندارد. برای اعتماد باید آن را آگاهانه در دستگاه یا مرورگر نصب کنید.

چرا بعد از نصب، بعضی برنامه‌های Android هنوز خطا می‌دهند؟

بسیاری از برنامه‌های جدید Android به‌طور پیش‌فرض به گواهی‌های نصب‌شده توسط کاربر اعتماد نمی‌کنند. تنظیمات Network Security Configuration یا certificate pinning برنامه می‌تواند بر نتیجه اثر بگذارد.

آیا نصب این Root CA فقط به سایت CA-Panel اعتماد می‌کند؟

خیر. نصب Root CA به دستگاه اجازه می‌دهد گواهی‌هایی را که این مرجع صادر می‌کند معتبر بداند؛ این اعتماد محدود به دامنه پنل نیست. فقط در صورت پذیرش این محدوده اعتماد آن را نصب کنید.

آیا می‌توانم آن را روی دستگاه شخص دیگری نصب کنم؟

فقط با رضایت آگاهانه مالک یا مدیر مجاز دستگاه، توضیح محدوده اعتماد و تطبیق اثر انگشت از یک کانال مستقل.

CA-Panel · Certificate Trust Center
این صفحه راهنمای نصب یک Root CA خصوصی است و به معنی عضویت آن در برنامه‌های عمومی اعتماد مرورگرها نیست.
