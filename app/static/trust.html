در حال بررسی اتصال امن به سامانه…

مرورگر در حال آزمایش بارگذاری یک تصویر عمومی از HTTPS است. هیچ اطلاعات محرمانه‌ای ارسال نمی‌شود.

آزمون اتصال HTTPS موفق نبود. ممکن است علت آن مورداعتمادنبودن گواهی، اختلال شبکه یا مسدودشدن تصویر باشد. برای اتصال امن، راهنمای زیر را بررسی کنید.
توجه: این صفحه با HTTP باز شده است. ارتباط این صفحه رمزنگاری و احراز هویت نشده است. اینجا هیچ رمز عبور، کد MFA، اطلاعات حساب یا درخواست صدور گواهی وارد نکنید.
راهنمای اتصال امن به سامانه

گواهی امنیتی این سامانه باید مورد اعتماد مرورگر شما باشد.

«گواهی دیجیتال ایران» از یک Root CA اختصاصی استفاده می‌کند. اگر مرورگر هشدار «مرجع صادرکننده ناشناخته» نمایش می‌دهد، ممکن است گواهی ریشه هنوز در دستگاه شما مورد اعتماد قرار نگرفته باشد.

برای ورود امن، ابتدا هویت گواهی ریشه را از مسیر مستقل تأیید کنید و سپس آن را فقط با تأیید مدیر یا مالک دستگاه در مخزن گواهی‌های مورد اعتماد نصب کنید.

سه گام برای اتصال امن

  1. ۱

    دریافت گواهی عمومی ریشه

    گواهی عمومی Root CA را مستقیماً از مدیر سامانه یا یک کانال مستقل و از قبل مورد اعتماد دریافت کنید. این سایت روی HTTP هیچ فایل یا گواهی برای دانلود ارائه نمی‌کند.

  2. ۲

    تأیید مستقل اثر انگشت SHA-256

    اثر انگشت واقعی گواهی را از مدیر CA و از کانالی مستقل و معتبر (مثلاً حضوری یا پیام امضاشده از منبعی از قبل مورد اعتماد) دریافت کنید. سپس با فایل دریافتی خودتان مقایسه کنید. به اطلاعات نمایش‌داده‌شده روی HTTP به‌تنهایی برای تشخیص اصالت اعتماد نکنید.

    Windows (CMD / PowerShell)certutil -decode iran-ca-center-root.pem iran-ca-center-root.cercertutil -hashfile iran-ca-center-root.cer SHA256
    Linux / macOS (OpenSSL)openssl x509 -in iran-ca-center-root.pem -noout -fingerprint -sha256
  3. ۳

    نصب گواهی و ورود از HTTPS

    فایرفاکس: Settings ← Privacy & Security ← Certificates ← View Certificates ← Authorities ← Import. فایل ریشه را انتخاب کنید و فقط پس از بررسی اثر انگشت تأیید کنید.

    ویندوز: با اجازه مالک یا مدیر دستگاه، فایل ریشه را در Trusted Root Certification Authorities نصب کنید. این کار به کل Root CA برای اعتبارسنجی گواهی‌ها اعتماد می‌دهد، نه فقط به همین سایت.

    بازگشت به ورود امن HTTPS
این آدرس HTTP فقط یک صفحه راهنما است. هیچ فایل، گواهی یا سرویس دیگری روی HTTP ارائه نمی‌شود؛ تمامی عملیات مدیریتی و صدور گواهی فقط روی HTTPS انجام می‌شوند.
